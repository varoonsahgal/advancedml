The honeycomb

16 labs. Zero setup.

Each lab is a guided Jupyter notebook: intuition first, then the math, then code you write yourself, with checkpoints that confirm you got it right. Open any of them in Colab with one click.

Lab progress

Tick "Mark complete" on each lab to fill its cell. Progress is saved in this browser.

Anatomy of a lab
🗺️ roadmap🎯 objectives🔮 predict-then-run🧪 your turn✅ solutions✔️ checkpoints🍯 key takeaways🏆 boss level💼 interview corner🐝 fun fact
  1. Predict the outcome before you run each key experiment.
  2. Build it from scratch in the 🧪 cells. Hints are right there, and solutions follow if you're stuck.
  3. Verify: the ✔️ checkpoints compare your code with a reference implementation.
  4. Compare with the production library you'll use at work.
  5. Consolidate with key takeaways, interview questions and a 🏆 stretch challenge.

Gradient Boosting From Scratch

Build gradient boosting with nothing but decision trees and calculus, watch each tree fit the previous residuals, then race your version against HistGradientBoosting and LightGBM on real data.
