Day 1 · Mon

Classical, Sharpened

Key equations

Bias–variance$$\mathbb{E}[(y-\hat f)^2] = \text{bias}^2 + \text{var} + \sigma^2$$
Boosting step$$F_m = F_{m-1} + \nu\, h_m,\quad h_m \approx -\nabla_F L$$
XGBoost leaf weight$$w^* = -G/(H+\lambda)$$
ECE$$\sum_b \tfrac{|S_b|}{n}\,|\mathrm{acc}(b) - \mathrm{conf}(b)|$$
Split conformal$$\hat q = Q_{\lceil (n+1)(1-\alpha)\rceil / n}(|y-\hat\mu(x)|)$$
Shapley value$$\phi_i = \sum_{S} \tfrac{|S|!(|F|-|S|-1)!}{|F|!}[v(S\cup i) - v(S)]$$

Key takeaways

  • Expected test error = bias² + variance + noise. Capacity trades the first two; nothing beats the third.
  • Past the interpolation threshold, adding parameters can reduce test error (double descent). Implicit regularization decides which solution you get.
  • Boosting is gradient descent in function space: each tree fits the negative gradient of the loss.
  • Small learning rate + many trees + early stopping on validation data beats big steps. Your baseline for any table is a GBDT.
  • Accuracy ≠ calibration. Fit Platt, isotonic or temperature scaling on held-out data to make confidences honest.
  • Split conformal: take a quantile of held-out residuals and get ≥ 1−α coverage for any model. The guarantee is marginal, so check your subgroups.
  • SHAP explains the model, not the world. Correlated features split credit unpredictably.
  • Tabular foundation models (TabPFN) do in-context learning on small tables in one forward pass, and often beat tuned GBDTs there.

Day 2 · Tue

The Deep Learning Engine Room

Key equations

Adjoint recursion$$\bar v_i = \sum_{j\in\text{ch}(i)} \bar v_j\, \partial v_j/\partial v_i$$
He init$$\mathrm{Var}(w) = 2/\text{fan}_{\text{in}}$$
RMSNorm$$x / \sqrt{\overline{x^2}+\epsilon}\odot g$$
AdamW$$\theta \leftarrow \theta - \eta\big(\hat m/(\sqrt{\hat v}+\epsilon) + \lambda\theta\big)$$
Muon$$\Delta W \propto \mathrm{NS}(M) \approx UV^\top$$
Chinchilla$$L(N,D) = E + A/N^{\alpha} + B/D^{\beta},\ C\approx 6ND$$

Key takeaways

  • Reverse-mode autodiff gives every gradient of a scalar loss for roughly the cost of a forward pass, at the price of storing activations.
  • Trainability comes from variance-preserving init, (pre-)normalization, and residual streams that carry gradients straight through.
  • AdamW (Adam + decoupled weight decay) is the default for transformers. L2 inside Adam is not the same thing.
  • Muon orthogonalizes the momentum of 2-D weight matrices. It's a strong 2025-era alternative for hidden layers.
  • The learning rate is hyperparameter #1. Use warmup, then cosine or WSD decay, and clip gradients.
  • Grokking: generalization can arrive long after memorization, and weight decay is what pushes the model there.
  • Compute-optimal training scales N and D together (~20 tokens/param), but production models over-train small models because inference is what costs money.

Day 3 · Wed

Transformers & Beyond

Key equations

Attention$$\mathrm{softmax}(QK^\top/\sqrt{d_k} + M)\,V$$
RoPE identity$$\langle R_m q, R_n k\rangle = \langle q, R_{n-m} k\rangle$$
SwiGLU$$W_2(\mathrm{SiLU}(W_1x)\odot W_3x)$$
KV cache$$\text{bytes} = 2\,L\,H_{kv}\,d_h\,b\cdot T$$
Speculative accept$$\min\big(1,\ p(x)/q(x)\big)$$
Selective SSM$$h_t = \bar A_t h_{t-1} + \bar B_t x_t,\ y_t = C_t h_t$$

Key takeaways

  • Attention lets every token read from every earlier token, weighted by query–key match. The causal mask stops it from reading the future.
  • Scale logits by 1/√dk so the softmax doesn't saturate and gradients keep flowing.
  • RoPE rotates q and k by position, so scores depend only on relative offset.
  • The KV cache trades memory for compute. At long context it dominates serving cost, which is why GQA and latent attention exist.
  • Decoding settings (temperature, top-p, min-p) shape the output's character as much as fine-tuning does.
  • Speculative decoding is exact: the target model's distribution is preserved; only the speed depends on the draft model.
  • MoE separates parameters (memory) from FLOPs per token, and needs load balancing so experts don't collapse.
  • SSMs give linear-time, constant-memory sequence modeling. Input-dependent selectivity is what makes them work, and hybrids with attention are common.

Day 4 · Thu

Generative Worlds

Key equations

ELBO$$\log p(x) \ge \mathbb{E}_q[\log p(x|z)] - \mathrm{KL}(q(z|x)\|p(z))$$
DDPM loss$$\|\epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon, t)\|^2$$
Flow matching$$\|v_\theta(x_t,t) - (x_1 - x_0)\|^2,\ x_t=(1-t)x_0+tx_1$$
Sampling ODE$$dx/dt = v_\theta(x,t),\ t: 0\to 1$$
CFG$$(1+w)\,\epsilon_\theta(x,c) - w\,\epsilon_\theta(x,\varnothing)$$
InfoNCE$$-\log \frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ij}/\tau}}$$

Key takeaways

  • Diffusion, score models and flow matching are one family: a time-dependent field that carries a simple distribution to the data distribution.
  • Flow-matching loss: regress vθ(xt, t) onto x₁ − x₀. Training needs no simulation and is about as simple as it gets.
  • Sampling is ODE solving. Fewer steps are faster but blurrier; reflow and distillation fix that.
  • Classifier-free guidance trades diversity for fidelity: (1+w)·conditional − w·unconditional.
  • Latent diffusion + diffusion transformers (DiT) are the scalable recipe for images and video.
  • CLIP's contrastive loss builds a shared image–text space, which gives you zero-shot classification and retrieval.
  • Vision-language models feed vision-encoder tokens into an LLM through a small projector.

Day 5 · Fri

LLMs, Reasoning & Agents

Key equations

LoRA$$h = W_0x + \tfrac{\alpha}{r}BAx$$
DPO$$-\log\sigma\big(\beta\log\tfrac{\pi_\theta(y_w)}{\pi_{ref}(y_w)} - \beta\log\tfrac{\pi_\theta(y_l)}{\pi_{ref}(y_l)}\big)$$
GRPO advantage$$\hat A_i = (r_i - \bar r)/\sigma_r$$
PPO clip$$\min(\rho \hat A,\ \mathrm{clip}(\rho,1\pm\epsilon)\hat A)$$
pass@N$$1-(1-p)^N$$
SAE$$\|x-\hat x\|^2 + \lambda\|f\|_1,\ f=\mathrm{ReLU}(W_e(x-b_d)+b_e)$$

Key takeaways

  • Knowledge mostly comes from pretraining. Post-training shapes behaviour: format, helpfulness, judgment, reasoning.
  • LoRA learns a low-rank update ΔW = (α/r)·BA. Merge it for zero latency; QLoRA keeps the frozen base in 4-bit.
  • DPO optimizes preference pairs directly, with no reward model and no RL loop, anchored to a reference model.
  • GRPO: sample a group, normalize rewards within it, and push up the better-than-average answers. No critic needed.
  • Test-time compute (longer thinking, voting, verifiers) buys accuracy, especially where answers can be checked.
  • An agent is a while loop: think → call tool → observe. MCP lets any client use any tool server.
  • Treat everything an agent reads as data, not instructions. Prompt injection is the top agent risk.
  • Write evals before you optimize, and read your failures every week.
  • Sparse autoencoders pull interpretable features out of superposition, and adding a feature's direction can steer the model.
