The lecture decks

Slides that teach.

One deck per day, plus a welcome deck for the first morning. Each is built from the same figures, labs and key takeaways as the course pages, and runs right in your browser: full-screen it, project it, or print it to PDF.

🎤 Presenting

  • → / Space next, ← back. Some slides reveal step by step.
  • F full screen · O overview of every slide · B blackout.
  • N opens speaker notes, with timing and talking points.
  • Type a number and press Enter to jump; links like day-3.html#12 open a specific slide.

🖨️ Handouts & PDF

Click Print / PDF on any deck (or press P inside it). In the print dialog, choose Save as PDF and turn on Background graphics. Every slide becomes one 16:9 page, with all steps revealed.

The decks are plain HTML in site/slides/. Edit them and run python scripts/build.py.
