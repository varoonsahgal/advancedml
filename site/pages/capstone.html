Project ideas

Steal one, remix one, or pitch your own. Each idea links back to the labs it builds on.

Classical · Labs 1.1–1.3

🏥 The honest predictor

Take a real tabular dataset (health, housing, churn). Ship a GBDT with conformal intervals, per-subgroup coverage checks, SHAP explanations, and a TabPFN comparison, all in one clean report.

Classical · Lab 1.2

🎯 Calibrate an LLM

Ask an LLM multiple-choice questions, extract its answer probabilities, measure ECE, apply temperature scaling, and build conformal prediction sets so it knows when to say "I'm not sure".

Deep learning · Labs 2.2–2.3

🏎️ Muon vs AdamW, properly

A careful optimizer study: tune the LR for each optimizer, run multiple seeds, try two schedules, and report compute-to-target-loss on a small GPT. Present it like a paper.

Transformers · Labs 3.1–3.2

⚡ Make it fly

Take your Lab 3.1 GPT and make inference as fast as you can: KV cache, int8 weights, speculative decoding with a tiny draft model. Plot tokens/sec at every step and check output quality.

Architectures · Lab 3.3

🐍 The recall showdown

Attention vs. SSM vs. a hybrid on synthetic memory tasks (copying, associative recall, induction). Find the sequence length where each one breaks.

Generative · Labs 4.1–4.2

🎨 Few-step generator

Train flow matching on a small image set (emoji, sprites, FashionMNIST), then apply reflow or distillation and get good samples in 1–4 steps. Show a filmstrip and an FID-style metric.

Multimodal · Lab 4.3

🔎 Search your photos

Build a CLIP-powered natural-language search over a folder of images, with an eval set of queries and recall@k. Bonus: add a reranker.

LLMs · Labs 5.1–5.2

🧮 Tiny reasoner

SFT a small model on a reasoning format, then GRPO it on a verifiable task (arithmetic, Countdown, Sudoku-lite). Plot the reward curve, then accuracy vs. samples with majority voting.

Agents · Lab 5.3

🛠️ An MCP toolbox

Write an MCP server for something you care about (your notes, a public API, a database), connect it to an agent, write 20 eval tasks, and measure the pass rate. Include a prompt-injection red-team.

Interpretability · Lab 5.4

🔬 Feature safari

Train a bigger SAE on GPT-2, catalogue 20 interesting features with evidence, and show one convincing steering demo. Bonus: an auto-interpretation pipeline that uses an LLM to label features.

📦 Deliverables

  • A repo or notebook that runs top to bottom
  • A README: problem → approach → results → limitations
  • One eval with numbers you trust (and how you know)
  • A 5-minute demo: live if you dare, recorded if you're wise
  • One failure you analyzed honestly

🧭 Tips from past hives

  • Get a baseline working in the first hour. Then improve it.
  • Pick a scope you can finish by Thursday night; Friday is for polish.
  • Plots beat tables, and one great plot beats ten okay ones.
  • Write the eval before you start tuning.
  • Split roles: builder, evaluator, storyteller.
