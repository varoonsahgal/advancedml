01Attention from first principles

Attention is a soft, differentiable dictionary lookup. Each token emits a query ("what am I looking for?"), a key ("what do I contain?") and a value ("what will I hand over if chosen?"). A token's output is the average of all values, weighted by how well its query matches each key.

Scaled dot-product attention
$$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}} + M\Big)V, \qquad M_{ij} = \begin{cases}0 & j \le i\\ -\infty & j > i\end{cases}$$

If the entries of q and k have unit variance, $q\cdot k$ has variance $d_k$. Dividing by $\sqrt{d_k}$ keeps the softmax out of its saturated, zero-gradient regime. The causal mask $M$ stops a token from peeking at the future.

def causal_self_attention(x, W_qkv, W_o, n_heads):
    B, T, C = x.shape
    q, k, v = (x @ W_qkv).split(C, dim=-1)
    q, k, v = [t.view(B, T, n_heads, C // n_heads).transpose(1, 2) for t in (q, k, v)]  # (B, h, T, d)
    att = (q @ k.transpose(-2, -1)) / math.sqrt(k.size(-1))
    att = att.masked_fill(torch.triu(torch.ones(T, T, dtype=torch.bool), 1), float("-inf"))
    y = att.softmax(-1) @ v                              # (B, h, T, d)
    return y.transpose(1, 2).reshape(B, T, C) @ W_o      # concatenate heads, project

02The modern block (2017 → 2026)

The original 2017 Transformer and a 2026 open-weights LLM differ mostly in small choices that add up to large gains in stability and efficiency. This is the "Llama-style" block you'll build in Lab 3.1:

🌀 RoPE: positions as rotations

Rotary position embedding (Su et al., 2021) splits q and k into 2-D pairs and rotates pair $i$ by angle $m\theta_i$, where $m$ is the token position and $\theta_i = 10000^{-2i/d}$. Rotations preserve length, and the dot product of two rotated vectors depends only on the difference of their angles. So attention scores become a function of relative position:

The RoPE identity
$$\langle R_{m} q,\; R_{n} k\rangle = \langle q,\; R_{n-m}\,k\rangle$$
SwiGLU MLP
$$\mathrm{SwiGLU}(x) = W_2\big(\mathrm{SiLU}(W_1 x) \odot W_3 x\big), \qquad \mathrm{SiLU}(z) = z\,\sigma(z)$$

One branch decides how much of the other to let through: a learned, smooth gate.

03Inference engineering

Generation has two phases. Prefill processes the whole prompt in parallel and is compute-bound. Decode produces one token at a time and is memory-bandwidth-bound: each new token needs the keys and values of every previous token. Recomputing them every step would cost $O(T^2)$ per token, so we store them in a KV cache, and that cache becomes the main memory cost of serving.

⚡ FlashAttention

Attention is limited by memory traffic, not arithmetic. FlashAttention (Dao et al., 2022) tiles Q, K, V into on-chip SRAM and uses an online softmax, so the full T×T matrix never touches GPU main memory. The output is exactly the same, it's several times faster, and memory is linear in T.

📄 PagedAttention

vLLM (Kwon et al., 2023) stores the KV cache in fixed-size pages, like OS virtual memory. That removes fragmentation and lets requests share prefixes, which allows much larger batches and higher throughput.

🏎️ Speculative decoding

A small draft model guesses k tokens and the big model checks them all in one forward pass. Each token is accepted with probability $\min(1, p(x)/q(x))$; on rejection you resample from $\max(0, p-q)$. The output distribution is exactly the big model's. You'll verify this in Lab 3.2.

🗜️ Quantization

Store weights in int8, int4 or fp8 instead of bf16, which cuts memory and bandwidth 2–4×. Outlier weights ruin per-tensor scales, so practical schemes use group-wise scales (e.g. one per 64–128 weights) and error-aware methods such as GPTQ and AWQ.

04Decoding: turning logits into words

The model outputs a distribution over the next token. How you sample from it changes the output's character more than most fine-tuning does. Temperature sharpens or flattens the distribution. Top-k keeps the k most likely tokens. Top-p (nucleus) keeps the smallest set whose total probability reaches p. Min-p drops any token less than p × the top token's probability, so it adapts to how confident the model is.

Buzz says

Greedy decoding isn't "the most accurate". It tends to loop and produce bland, repetitive text. Reasoning models are typically sampled at a moderate temperature, and that's partly why majority voting over several samples helps (Day 5).

05Mixture-of-Experts: more parameters, same FLOPs

Replace the single MLP with $E$ expert MLPs and a tiny router that sends each token to its top-k experts. Total parameters grow with $E$, but the compute per token only grows with k. That decouples knowledge capacity from cost per token.

Top-k routing
$$y = \sum_{e \in \mathrm{TopK}(r(x))} \frac{\exp r_e(x)}{\sum_{e'\in \mathrm{TopK}} \exp r_{e'}(x)}\; \mathrm{Expert}_e(x), \qquad r(x) = W_r x$$
Frontier MoEs

Mixtral 8×7B (2024) routes each token to 2 of 8 experts. DeepSeek-V3 (2024) has 671B total parameters but only ~37B active per token, using many fine-grained experts plus always-on shared experts, latent attention (MLA) for a small KV cache, and a bias-based balancing scheme without an auxiliary loss. Many of the strongest open-weights models in 2025–26 are MoEs.

06State-space models: attention's challengers

Attention compares every token with every other: $O(T^2)$ compute and a KV cache that grows with T. A state-space model compresses the past into a fixed-size state and updates it with a linear recurrence. That means $O(T)$ compute and constant memory per generated token.

Selective SSM (Mamba)
$$h_t = \bar A_t\, h_{t-1} + \bar B_t\, x_t, \qquad y_t = C_t\, h_t, \qquad (\Delta_t, B_t, C_t) = f(x_t)$$

Earlier SSMs used fixed A, B, C. Mamba (Gu & Dao, 2023) makes them depend on the input, so the model can choose what to remember and what to forget. Because the recurrence is linear in h, it can still be computed with a parallel associative scan, which you'll implement in Lab 3.3.

🔦 Attention is great at…

  • Exact recall of anything in the context
  • Copying, lookup, in-context learning
  • Parallel training on GPUs

🐍 SSMs are great at…

  • Very long sequences at linear cost
  • Constant-memory, fast generation
  • Smooth, continuous signals (audio, genomics)

The practical answer in 2025–26 is often hybrids: mostly SSM or linear-attention layers with a few full-attention layers mixed in for precise recall (e.g., AI21's Jamba, 2024). In Lab 3.3 you'll see both sides. On selective copying, a non-selective SSM fails while the selective one matches attention. Then, at 4× the training length, the SSM keeps working while attention falls apart. Input-dependent gating is what makes the difference.

08Quiz: check your honey

Score: 0 / 5

Why divide the attention logits by √dk?
With unit-variance entries, q·k has variance dk. Large logits make the softmax nearly one-hot, and its gradient nearly zero.
What does the KV cache store, and why?
Keys and values of earlier tokens don't change in a causal model, so caching them avoids recomputing the whole prefix at every step.
The key property of RoPE is that the attention score between positions m and n depends on…
Rotations compose: (Rmq)·(Rnk) = q·(Rn−mk). Relative position falls out automatically.
A model has 671B total parameters but 37B active per token. Which statement is true?
MoE saves FLOPs per token, not memory. All experts must be resident (or sharded across devices).
Speculative decoding with the min(1, p/q) acceptance rule produces outputs that are…
The accept/reject plus residual-resampling scheme is a form of rejection sampling that recovers the target distribution exactly. Only the speed depends on how good the draft is.
